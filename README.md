# Gemini for Pixel 10a

A minimal Android launcher app that opens the official Gemini website in a Chrome Custom Tab.

## Important
- This is an independent launcher, not an official Google app.
- Google sign-in is handled by the browser, not by an embedded WebView.
- Chat history, voice, uploads and other features are provided by the official Gemini website and depend on Google's account, region and service availability.
- This app does not bypass regional restrictions and cannot guarantee Gemini service availability in Russia.
- The app itself can remain installed even if Gemini is unavailable.

## Build APK
Push this project to a GitHub repository. The included GitHub Actions workflow builds a debug APK on every push to `main`, or when manually started from Actions.

Artifact name: `Gemini-Pixel10a-debug`.
